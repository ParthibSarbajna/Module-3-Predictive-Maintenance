
# Module 3 Project Outputs

This directory contains the outputs generated by the
Predictive Maintenance and Vehicle Health Monitoring project.

## Graphs

The `graphs/` directory contains the visualizations generated
during model evaluation and analysis.

## Results

The `results/` directory contains:

- Cleaned dataset
- Model comparison
- XGBoost feature importance
- SHAP feature importance
- Sample predictions
- Project metadata

## Models

The `models/` directory contains the trained:

- Random Forest model
- XGBoost model

## Project Summary

`PROJECT_SUMMARY.txt` contains a summary of the complete
project pipeline and generated outputs.
